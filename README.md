# Diyorbek Kimsanov — UI/UX Dizayner va Frontend Dasturchi Portfoliosi

Semantik HTML5, modulli CSS3 va toza JavaScript (ES6+) asosida yaratilgan zamonaviy, tezkor va to'liq moslashuvchan shaxsiy portfolio veb-sayti. Loyiha dizayn yechimlari, bajarilgan ishlar ko'rgazmasi va professional hamkorlik takliflarini taqdim etish uchun mo'ljallangan.

---

## Umumiy Ma'lumot

Ushbu repozitoriy UI/UX dizayn, interaktiv prototiplash va frontend dasturlash bo'yicha mutaxassis Diyorbek Kimsanovning rasmiy portfolio saytini o'z ichiga oladi.

Loyiha hech qanday tashqi freymvorklar, og'ir kutubxonalar yoki yig'ish (build) vositalariga tayanmasdan, sof veb standartlariga qat'iy rioya qilgan holda ishlab chiqilgan. Bu esa sahifaning bir zumda yuklanishini va yuqori unumdorlikni ta'minlaydi.

---

## Asosiy Imkoniyatlar

- Modulli CSS Arxitekturasi: Har bir bo'lim va vazifa alohida CSS fayllarga ajratilgan hamda yagona `main.css` kirish nuqtasi orqali boshqariladi.
- Mustaqil va Toza Kod (Zero-Dependency): Tashqi kutubxonalarsiz, faqat sof HTML5, CSS3 va JavaScript (ES6+) imkoniyatlaridan foydalanilgan.
- To'liq Moslashuvchan Dizayn: Barcha turdagi qurilmalar (smartfon, planshet, noutbuk va keng ekranli monitorlar) uchun moslashtirilgan.
- Interaktiv Xizmatlar va Portfolio Filtrlash: Mijozlar va rekruterlar uchun yo'nalishlar bo'yicha filtrlash va har bir xizmat haqida batafsil ma'lumot olish imkoniyati.
- Foydalanuvchi Tajribasi (UX): Aniq vizual iyerarxiya, ergonomik tugmalar, zamonaviy qorong'i (dark) mavzu va silliq mikro-animatsiyalar.
- Aloqa va Hamkorlik: Rezyumeni (CV) yuklab olish tugmasi, xizmatlarga buyurtma berish hamda to'g'ridan-to'g'ri bog'lanish shakllari.

| Yo'nalish | Texnologiyalar | Vazifasi |
|---|---|---|
| Dizayn va Prototiplash | Figma | Interfeys dizayni, wireframe, foydalanuvchi oqimlari (UX flows) va dizayn tizimi |
| Hujjat Tuzilmasi | Semantik HTML5 | Sahifaning to'g'ri semantik karkasi, qulay o'qiluvchanlik va qidiruv tizimlariga moslik (SEO) |

| Mantiq va Interaktivlik | Sof JavaScript (Vanilla ES6+) | DOM bilan ishlash, filtrlash mantiqi, modal oynalar va hodisalarni boshqarish |
